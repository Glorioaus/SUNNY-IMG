# SUNNY 粒子汇聚展示 - 项目总结

## 项目概述

本项目实现了一个视觉效果丰富的粒子汇聚网页，图片粒子会从随机位置开始以波动方式运动，最终汇聚成"SUNNY"字样。项目采用前后端分离架构，前端使用原生HTML/CSS/JavaScript实现，后端提供图片服务。

## 主要功能实现

### 1. 粒子系统核心

**粒子类 (Particle)**
- 每个粒子维护自己的位置、速度和波动相位
- 实现了波动运动算法：结合正弦波和余弦波
- 边界碰撞检测：粒子到达边界时反弹
- 交互支持：点击粒子产生随机加速度

**运动算法**
```javascript
this.wavePhase += CONFIG.waveFrequency;
const waveX = Math.sin(this.wavePhase) * CONFIG.waveIntensity;
const waveY = Math.cos(this.wavePhase * 0.8) * CONFIG.waveIntensity;

this.x += this.vx + waveX * 0.1;
this.y += this.vy + waveY * 0.1;
```

### 2. 汇聚算法

**字母粒子生成**
- 使用5x5网格定义每个字母的点阵模式
- 为S、U、N、N、Y五个字母分别定义点阵
- 根据屏幕尺寸自动调整字母位置和大小

**汇聚控制**
```javascript
setParticleTargets() // 设置目标位置
isConverging = true;  // 开始汇聚模式
```

### 3. 后端集成

**API调用**
- 从后端获取图片列表
- 错误处理：后端不可用时使用备用图片
- 图片预加载机制

**故障转移**
```javascript
try {
    const response = await fetch(`${CONFIG.backendUrl}/api/images`);
    const data = await response.json();
    // 使用后端图片
except (error) {
    console.error('Failed to fetch images from backend:', error);
    loadFallbackImages(); // 使用备用图片
}
```

### 技术选型考量

**不使用框架的原因**
- 轻量级：减少不必要的依赖
- 快速加载：单个HTML文件
- 便于维护：简洁的代码结构
- 高性能：无框架性能开销

**Canvas vs DOM粒子**
选择DOM粒子的原因：
- 简单直观：直接使用img元素
- 交互方便：原生事件支持
- 易于调试：可以直接在浏览器中查看元素
- 性能足够：100个粒子完全流畅
